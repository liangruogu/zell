## Bindle项目简介

Bindle 意为把某个项目的所有资料，context打包，呈现在同一个地方

痛点：

- 每次项目跟进都需要找到之前的进度以及资料，没有统一管理（ppt、word等等)
- AI生成需要context，每次都需要反复输入相同的提示词，并告诉AI项目背景（例如生图需要反复说明风格）
- Markdown协作编辑，导入成Word 每次的Word格式调整都十分麻烦
- 可视化操作，优化指定文字等等

技术栈选择（软件Tarui/自托管后端Go）：

- 以快速推进实现效果为主要目的，但要求跨操作系统（Windows / Mac / Linux发行版）希望安装包小一点

- 全部开源，可使用自己的服务器进行自托管（给团队一起使用），支持Docker

功能列表：

1. 创建项目（填写项目背景/基础信息 可随时修改）
2. 知识库（类似飞书，以Markdown作为报告的基础形式）可导出成Word、pdf (不能直接pandoc直接导出，需要设置Word样式，避免还需要打开Word修改格式)
3. 可以链接外部资源（例如可画ppt，github代码仓库等等，提供skills给AI阅读，人类可以一键打开网页）
4. 头脑风暴区域（要求有画笔、文字、方框【带不同样式例如颜色，线条样式等等】、箭头等等）头脑风暴区支持AI辅助思维发散和原型生成（图片生成） 选中文本可以@AI 进行图片生成或者思维发散
5. 上述三个功能经过分享后可以生成访问链接，邀请同事加入（我不清楚如果这样是否需要添加登录功能，但是我不希望这样，可不可以只使用类似密钥之类的，邀请成功后会有一个密钥识别用户身份，项目所有者可以自主命名其他所有人即可）



Context部分是难点部分，常见的资料包括：

- PPT
- PDF
- Word
- 网页链接



现在我们的场景还是不够清晰：

场景应该不是写代码，而是设计（画图、生成原型）这样的设计功能

原型生成应该是包括一切AIGC生图工作（包括生成logo，品牌场景等等）

后序我想拓展的（可能比较难，把Figma的功能搬进来，然后让AI和人一起做交互设计原型（包括网站，app等等）



目前来看，其实共享编辑Markdown把这个功能做好了其实就很牛了（需要像overleaf一样加一个历史版本保存和实时保存的可选功能），然后这样文书部分可以一起写，而且可以让AI帮我们优化我们指定的文字部分。

导出功能也是一大利器，无论是PDF还是Word都是很棒的



总结一下，其实现在的场景主要是两个：

1. 共享编辑Markdown（加入带上下文信息的AI功能，并让导出效果更好，不需要反复修改Word格式）

这里其实有三个痛点： 1、共享编辑Markdown 2、带项目上下文的AI功能 3、Word格式不需要反复调

2. 头脑风暴以及原型制作（这是面向设计方向的利器，给基本的工具，可以实现大部分的效果，再把AI生图功能加进去基本覆盖90%的头脑风暴场景）
